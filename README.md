# Pandubbi — Web Crawler

Pandubbi is a Rust-based web crawler project developed as a foundation for an independent search engine.

## Features
- Public web page crawling
- Page title and text extraction
- Link discovery
- Image metadata extraction
- Configurable crawl limits
- Local storage of crawl records
- Respect for website crawling policies

## Platforms
- Android Termux
- Linux

## Project Status
Under active development.

This public repository contains project information only. The source code is maintained separately.
